# LUMIÈRE – Luxury Restaurant Website

LUMIÈRE is a modern and responsive restaurant website designed with a luxurious and elegant visual style. The website provides visitors with information about the restaurant, menu, gallery, and contact details, along with an interactive table reservation system.

## Features

* Responsive design for desktop and mobile devices
* Modern luxury restaurant interface
* Interactive navigation and mobile menu
* Restaurant menu section
* Image gallery
* Table reservation form
* Date validation for reservations
* Reservation data stored securely in Supabase
* Live deployment using Vercel

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Supabase
* Vercel
